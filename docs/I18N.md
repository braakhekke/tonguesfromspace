# Languages: English, German, French (i18n)

The site is in **English** (source), **German** and **French**. The language is in the **address**: `https://tonguesfromspace.org/…` is English, `/de/…` German, `/fr/…` French (`/de/size`, `/fr/switzerland/aletsch/`, `/de/gallery`). Added 2026-11-14.

**Rule (owner, 2026-11-14): whenever anything is added to a page or a text is edited, every language is brought along in the same change.** An English text without its entries shows in English on the other pages (the intended fallback: never a wrong translation), but it is not finished until `de` and `fr` have it.

German is Swiss standard German (*ss* for *ß*, 1’291, «guillemets», "du"). French is Swiss French (« guillemets », a narrow no-break space in 1 291 and before `: ; ! ? »`, "vous" in sentences and the infinitive for buttons: *Choisir*, *Comparer*). In both the **decimal point stays** (75.79 km²) and external figures are copied from the English text, digits only (the rule on external numbers).

## How it works

- **Addresses.** On the public site the Worker (`worker/main.ts`) answers `/de/<path>` and `/fr/<path>` with the file of `/<path>`: the same pages, the same data, the same relay and gallery paths (`run_worker_first` in `wrangler.toml` lists the prefixes). It sets `<html lang>`, the canonical and `og:url` addresses of the language, and names the files (`css/`, `js/`, `data/`, `images/`, `config.js`) from the root, so one file is one cache entry in every language. `/de` goes to `/de/`; a missing address under the prefix is the 404 page in that language. `scripts/serve.py` and the test server do the same locally. `scripts/build_site.py` adds `hreflang` alternates after the canonical link of every page and lists every address three times in the sitemap.
- **`js/i18n.js`** (classic script in the `<head>` of each page, after `config.js`): reads the language from the path, sets `<html lang>` and `data-i18n-long` (CSS for the longer languages hangs on it), loads `js/i18n-<lang>.js` and translates the page as it is built **and as scripts change it** (MutationObserver). Root-absolute links to our own pages (`/size`, `/provenance.html?id=…`, `/switzerland/`) are given the prefix. `?lang=de` (the old way) redirects to the address.
- **The switch** is three plain links to the same page in each language (search and `#hash` are kept; the hash is read when the link is used). **Explorer and size page:** next to the social icons at the foot of the right panel (the panel is redrawn; `js/i18n.js` puts it back) and, on phones, in the phone menu and under the card. **Home, gallery, field notes:** a drop-down (`EN ▾`) in the header; **404:** a fixed drop-down.
- **`js/i18n-de.js`, `js/i18n-fr.js`** are **generated** (`window.TFS_DE`, `window.TFS_FR`), never edited by hand.
- What is translated: text nodes, `title`, `aria-label`, `placeholder`, `alt`, `data-why`, and the page title. Text drawn on a canvas (export pictures, video, 3D labels, legends) goes through the same dictionary: `js/i18n.js` wraps `fillText`, `strokeText` and `measureText` of the canvas (with a memo); code can also call `window.tfsT(text)`.
- **Text that lives in CSS** (`content:'…'`) is not in the page and cannot be translated by the dictionary: give it a line per language under `html[lang="de"]` / `html[lang="fr"]` (today only the "Shrink / Enlarge view" pill, `#miniToggle`). The same for text in an SVG or an image.
- Names (glaciers, places) and numbers are never keys. Months (`12 September` → `12. September` / `12 septembre`, `1er`), `by X` (`von`, `par`), `m/yr` (`m/Jahr`, `m/an`) and the thousands separator are rules in `js/i18n.js` (table `LX`).

## The dictionary

`i18n/<lang>.json` (key → text) and `i18n/extra.json` (German) / `i18n/extra-fr.json` (French) (hand-written entries and templates) → `python3 scripts/i18n/tool.py build --lang de|fr` → `js/i18n-<lang>.js`. `i18n/todo.json` (not committed) is the one list of English keys. Key forms:

| Key | Matches |
|---|---|
| plain text | one text node or attribute (white space collapsed) |
| `<>…` with `⟨a⟩ ⟨b⟩ …` | the inner HTML of an element with inline markup; every tag is a token `⟨a⟩`, `⟨b⟩` … in order and the page puts **its own tags back**. The value must use the same tokens (build checks it). |
| `{#}` | every number (and a run of three or more plain number items, e.g. a list of dates, counts as one). Write `{#}` for each English number, in order, in the translation (or `{2}` to reorder) |
| `{}` / `{g}` in `extra*.json` | a template; `{g}` is one of the glacier names listed under `{names}`; the value uses `{1}`, `{2}` … |
| `a · b · c` | a string with ` · ` is translated piece by piece if the whole is not found |

An exact entry wins over a template. Identical English/target strings need no entry.

## Adding or changing a text (for every language)

1. Change the English text as always.
2. `python3 scripts/serve.py`, then per language `python3 scripts/i18n/collect.py OUT.json --lang de` (and `--lang fr`): it opens the pages with the debug switch `localStorage tfs-i18n-debug=1` and records what had no entry (add `--phone`, `--only explorer|size|home|prov|gallery`). `python3 scripts/i18n/tool.py add OUT.json` (once: the list of English keys is shared).
3. `python3 scripts/i18n/tool.py --lang fr list 150` prints the next untranslated strings, numbered; write `number<TAB>translation` lines in a file and `python3 scripts/i18n/tool.py --lang fr apply file.tsv` (a third column is the English key to store a template under). Strings left out of the file are recorded as "stays as it is" (names, numbers). Do the same for `--lang de`.
4. `python3 scripts/i18n/tool.py build --lang de` and `build --lang fr`. `tests/test_i18n.py` fails when a generated file is not current.

**The About chapters, glacier stories, sources lists and the field notes are English text in the code; when one changes, its entries no longer match and English shows until the dictionaries have the new text.**

## Layout

German and French are longer than English. `python3 scripts/i18n/layout_check.py [--lang de|fr] [--phone] [--shots DIR] [PAGE…]` loads each page in English and in the language and prints what happens only there (text clipped, cut with an ellipsis, spilling out of its box, off-screen, overlapping). Fixes sit under `html[data-i18n-long]` (both languages) in `css/style.css`, `css/home.css`, `gallery.html`, and in the CSS string of `js/i18n.js` (the switch itself). The checker is noisy for rotated text and sticky bars; look at the screenshots.

## Not done / known limits

- Texts inside exported pictures and videos: the legal credit line stays English (it is drawn word by word); composite labels built in code (e.g. "12 m since 2016") show English until their template is in `i18n/extra*.json`.
- Regions that are not public yet (Iceland, Norway, Svalbard): their long texts (`js/07a-region-icecaps.js`, `js/07b-icecap-texts.js`) are not in the dictionaries. The Tongla quiz (`js/mascot.js`) is translated; `play.html` (the mission sheets) does not load the dictionaries.
- A few strings are compared by code against the page text (`js/08-controls.js` `SAT_MSG`); in another language the comparison fails and a notice is not hidden automatically.
- Gallery items by visitors (names, captions) are not translated.
- The link-preview texts (`<title>`, `og:*`) of the language addresses are the English ones; only the language, canonical and alternate addresses differ.
