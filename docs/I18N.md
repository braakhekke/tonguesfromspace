# English / German (i18n)

Every page has an **EN | DE** switch (explorer, size page, gallery, front page, field notes, 404). English is the language of the source; German is a layer on top. Added 2026-11-14. Written in Swiss standard German: *ss* for *ß* (Grösse, Strasse), the decimal point stays (75.79 km²), thousands with an apostrophe (1’291), «guillemets».

## How it works

- `js/i18n.js` (classic script in the `<head>` of each page, after `config.js`): reads `localStorage 'tfs-lang'` (`"en"` default, `?lang=de` sets it once), puts the switch into the page's nav (`header.bar nav`, the explorer's `.site-nav`, the phone header `#mhead`; a fixed pill where there is none), and, for German, loads `js/i18n-de.js` and translates the page as it is built **and as scripts change it** (MutationObserver). Switching reloads the page, so the explorer's hash (`#g=…&m=…`) stays.
- `js/i18n-de.js` is **generated** (`window.TFS_DE`), never edited by hand.
- What is translated: text nodes, `title`, `aria-label`, `placeholder`, `alt`, `data-why`, and the page title. Code that draws text itself (canvas export) calls `window.tfsT(text)`; today `shadowText` / `fitText` in `js/10-animation.js` do.
- Names (glaciers, places) and numbers are never keys. External figures are not touched: numbers are copied from the English text (only the thousands separator changes).

## The dictionary

`i18n/de.json` (key → German) and `i18n/extra.json` (hand-written entries and templates) → `python3 scripts/i18n/tool.py build` → `js/i18n-de.js`. Key forms:

| Key | Matches |
|---|---|
| plain text | one text node or attribute (white space collapsed) |
| `<>…` with `⟨a⟩ ⟨b⟩ …` | the inner HTML of an element with inline markup; every tag is a token `⟨a⟩`, `⟨b⟩` … in order and the page puts **its own tags back**. The German value must use the same tokens (build checks it). |
| `{#}` | every number (and a run of three or more plain number items, e.g. a list of dates, counts as one). Write `{#}` for each English number, in order, in the German value (or `{2}` to reorder) |
| `{}` / `{g}` in `extra.json` | a template; `{g}` is one of the glacier names listed under `{names}`; the German value uses `{1}`, `{2}` … |
| `a · b · c` | a string with ` · ` is translated piece by piece if the whole is not found; `by X` → `von X`; dates `12 September` → `12. September` |

An exact entry wins over a template. Identical English/German strings need no entry.

## Adding or changing a text

1. Change the English text as always.
2. `python3 scripts/serve.py`, then `python3 scripts/i18n/collect.py OUT.json` (opens the pages in German with the debug switch `localStorage tfs-i18n-debug=1` and records what had no entry; add `--phone`, `--only explorer|size|home|prov|gallery`), `python3 scripts/i18n/tool.py add OUT.json`.
3. `python3 scripts/i18n/tool.py list 150` prints the next untranslated strings, numbered; write `number<TAB>German` lines in a file and `python3 scripts/i18n/tool.py apply file.tsv` (a third column is the English key to store a template under). Strings left out of the file are recorded as "stays as it is" (names, numbers).
4. `python3 scripts/i18n/tool.py build`. `tests/test_i18n.py` fails when `js/i18n-de.js` is not current.

**The About chapters, glacier stories, sources lists and the field notes are English text in the code; when one changes, its German entry no longer matches and the English shows until the dictionary has the new text.** That is the intended fallback (English, never a wrong translation).

## Layout

German is longer. `python3 scripts/i18n/layout_check.py [--phone] [--shots DIR] [PAGE…]` loads each page in both languages and prints what happens only in German (text clipped, cut with an ellipsis, spilling out of its box, off-screen, overlapping). Fixes sit under `html[lang="de"]` in `css/style.css`, `css/home.css`, `gallery.html`, and in the CSS string of `js/i18n.js` (the switch itself). The checker is noisy for rotated text and sticky bars; look at the screenshots.

## Not done / known limits

- Texts inside exported pictures and videos are translated only where they go through `shadowText` / `fitText`; the legal credit line in the picture stays English; other canvas labels (legend titles, 3D labels) stay English.
- Regions that are not public yet (Iceland, Norway, Svalbard): their long texts (`js/07a-region-icecaps.js`, `js/07b-icecap-texts.js`) are not in the dictionary.
- A few strings are compared by code against the page text (`js/08-controls.js` `SAT_MSG`); in German the comparison fails and a notice is not hidden automatically.
- Gallery items by visitors (names, captions) are not translated.
