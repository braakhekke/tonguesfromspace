Warm up the image cache

Requests every satellite image of the scenes in scenes.json once, in two kinds (the whole glacier area for the map, and the small strip picture the 3D view uses), through the relay, so that the relay's cache (Cloudflare KV, 180 days) already holds them when the first visitor comes. It runs the real code of index.html in a hidden frame, so the requests are exactly the ones the site makes. Run it after the deploy, from a copy of the same commit: python3 -m http.server 8000, then open http://localhost:8000/tools/warm-up.html. The relay allows that address. Each new image is one Copernicus request and one KV write (the free plan allows 1,000 writes a day); images already in the cache cost nothing. With both kinds and one colour style a full run is about 220 images (and so about 220 writes); with all three styles about 660, so spread that over days. The strip pictures are small and make the 3D view quick for the first visitor, who does not have to wait for Copernicus.
