    Select where the satellite images come from. EOX works right away. Copernicus needs a free account, but has every year from 2016 and allows commercial use.

    Selected: EOX annual mosaics

    EOxCloudless yearly cloud-free Sentinel-2 mosaics. 2016 is CC BY 4.0; later years are CC BY-NC-SA 4.0, so non-commercial use only. Only years EOX has actually published can be selected.

    Sentinel-2 quarterly cloudless mosaics from the Copernicus Data Space Ecosystem, using the July–September quarter of each year. Free for any use, including commercial. Every year from 2016 appears, and new ones are picked up automatically.

    Or paste an access token

    Create the client once in the Sentinel Hub section of your CDSE dashboard (shapps.dataspace.copernicus.eu → User settings → OAuth clients). Locally, start the dashboard with python3 scripts/serve.py; browsers block the Copernicus login otherwise. Credentials stay in this browser and go only to Copernicus, via serve.py on your own computer.
